## IDENTITY

Data Rehab is a fixed-scope margin recovery sprint. Not consulting. Not hourly. Not "call for custom quote." We diagnose data problems, quantify leakage, and fix the mess — fast, scoped, and priced up front.

Signed by August West, Co-founder. Positioning: before you automate anything, your data has to be clean. We are the prerequisite.

Company: Privium Data Services
Website: getdatarehab.com

## TARGET

SMB CFOs, Controllers, and operations leaders at companies with:
- Legacy ERP systems (QuickBooks, old Sage, BC, mixed Excel)
- Failed or stalled system migrations
- Manual reporting processes that take days
- Recent PE acquisition (new reporting requirements, old data)
- AI-curious but data isn't ready
- Multi-entity contractors or property operators with ugly legacy stacks

Primary verticals: Construction, Property Management, Professional Services, PE-backed specialty trades.

## PRIMARY PAIN POINTS

1. **Data Not AI-Ready** — They want automation but their source data is too messy to trust
2. **Migration Hangover** — Tried to move to a new system, now running two in parallel
3. **Excel Bridge Dependency** — Critical reports depend on a spreadsheet someone built 3 years ago
4. **Audit Prep Nightmare** — Takes weeks to pull clean data for auditors
5. **No Single Source of Truth** — Different numbers depending on which system you look at
6. **Leakage Nobody Sees** — Duplicate vendors, orphaned records, AR/AP mismatches eating margin

## PRICING LADDER

**Diagnosis only. This is the entry offer.**

Deliverables:
- 60-90 minute kickoff call
- Secure intake + system access checklist
- Review of up to 2 systems, 5 critical workflows, 10 core data objects
- Red / Yellow / Green scorecard
- Leakage map with quantified impact
- Top 10 data/control failures ranked by severity
- Prioritized rehab roadmap
- 60-minute findings call
- Written summary PDF

Best for: Skeptical buyers. First engagement. Leads who need proof before spending real money.

NOT included: Actual cleanup. Dashboard rebuild. Workflow automation. Custom integrations. This is diagnosis, not surgery.

**Guarantee:** "If the Data Autopsy does not identify a credible path to at least 3x ROI through leakage reduction, time savings, or control improvement, we credit 100% of the Autopsy fee and recommend no Sprint."

### 2. Data Rehab Sprint — Lite — $14,997

Deliverables:
- Everything from Autopsy applied into execution
- Cleanup of 1 system + 1 adjacent source
- Up to 10 tables / data objects
- Dedupe + normalization
- Mapping / field standardization
- Exception log
- Validation rules
- Close-risk issues surfaced
- 2 weekly working sessions
- Final rehab report + handoff

Good fit: One entity. Early-stage cleanup. Obvious AR/AP / vendor / customer / job master mess. No major custom integration.

### 3. Data Rehab Sprint — Core — $24,997

Good fit: Most real construction / property ops clients. Enough pain to matter, not full enterprise disaster.

### 4. Data Rehab Sprint — Complex — $39,997

## SCOPE RULES (in writing, every engagement)

Every package defines:
- Number of systems
- Number of entities
- Number of tables / data objects
- Number of workflows
- Number of reports / dashboards
- Support period
- Meetings included
- What is explicitly out of scope

Standard exclusions: "Excludes net-new ERP implementation, custom API development, historical backfill beyond 24 months, and ongoing managed services unless separately scoped."

**Sprint guarantee:** "If we fail to deliver the agreed scope and documented findings/remediation artifacts, we work until that scope is complete."
