## OPPORTUNITY CRITERIA

An opportunity is worth pursuing if:

| Criterion | Threshold |
|-----------|-----------|
| Addressable market | Businesses that can pay ($500+/mo) |
| Can be validated | Under 2 weeks with existing tools |
| Automation potential | High — agents can do most of the work |
| Margin profile | 70%+ gross margin (software/data/service) |
| Steve's existing edge | Uses construction, finance, or ops domain knowledge |
| Time to first dollar | Under 60 days |

### Strong YES signals:
- Boring, operational, repetitive workflow in a cash-rich industry
- Problem that construction CFOs or HOA managers complain about
- Data that exists but nobody is organizing or acting on
- A workflow where agents can replace humans at 10x speed

### Hard NO signals:
- Consumer apps
- VC-track startups requiring fundraising
- Markets dominated by well-funded incumbents with no wedge
- Anything requiring physical operations or inventory

## IDEA FILTERS

Before any new project gets resources, it must pass:

1. **Revenue test** — Can this generate cash in 60 days?
2. **Automation test** — Can 80%+ of the work be done by agents?
3. **Edge test** — Does Steve's construction/finance background give an unfair advantage?
4. **Leverage test** — Does this compound over time or stay linear?
5. **Exit test** — Could this become a product someone would buy?

If it fails 3 or more → deprioritize.
